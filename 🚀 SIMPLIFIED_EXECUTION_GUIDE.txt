═══════════════════════════════════════════════════════════════════════════

   CHECK IF NODE.JS IS INSTALLED:
   
   1. Open Command Prompt (cmd)
   2. Type: node --version
   3. Type: npm --version
   
   ✅ If you see version numbers → You're ready!

   INSTALL NODE.JS:
   
   1. Go to: https://nodejs.org/
   2. Download LTS version (left button)
   3. Run the installer
   4. Keep all default settings
   5. Restart your computer
   6. Try again


═══════════════════════════════════════════════════════════════════════════
                         🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

   PROBLEM: "npm is not recognized"
   ├─ Cause: Node.js not installed or not in PATH
   └─ Fix: Install Node.js from https://nodejs.org/ and restart PC

   PROBLEM: "Port 3000 already in use"
   ├─ Cause: Another app is using port 3000
   └─ Fix: Close backend window or restart computer

   PROBLEM: "Cannot find module 'express'"
   ├─ Cause: Dependencies not installed
   └─ Fix: Run "1_INSTALL_DEPENDENCIES.bat"

   PROBLEM: Blank page in browser
   ├─ Cause: Backend or frontend not running
   └─ Fix: Make sure BOTH servers are running (2 windows open)

   PROBLEM: Scripts won't run
   ├─ Cause: Windows security blocking
   └─ Fix: Right-click .bat file → "Run as administrator"
