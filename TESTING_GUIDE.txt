🔧 TROUBLESHOOTING

   → Try searching for common items like "laptop" or "gold"

   Problem: Error message appears
   → Make sure both servers are running
   → Check if backend is on port 3000

   Problem: Prices showing as $0.00
   → Refresh the browser (Ctrl + F5)
   → Should show ₹ symbol with proper amounts
