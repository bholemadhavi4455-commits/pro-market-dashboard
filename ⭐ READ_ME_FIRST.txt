   1. Double-click: "START_HERE.bat"

📋 MANUAL METHOD (3 STEPS):
═══════════════════════════════════════════════════════════════════════════

   STEP 1 (First time only):
   ► Double-click: "1_INSTALL_DEPENDENCIES.bat"
   
   STEP 2 (Every time):
   ► Double-click: "2_START_BACKEND.bat"
   ► Keep the window open!
   
   STEP 3 (Every time):
   ► Double-click: "3_START_FRONTEND.bat"  
   ► Keep the window open!
   ► Browser opens automatically to http://localhost:5173


⚠️ REQUIREMENTS:
═══════════════════════════════════════════════════════════════════════════

   Node.js must be installed!
   
   ✅ Check if installed:
      - Open Command Prompt (cmd)
      - Type: node --version
      - If you see a version number → You're ready!
      - If error → Install Node.js first
   
   📥 Download Node.js:
      https://nodejs.org/
      → Download the LTS version
      → Run installer
      → Restart computer
      → Try again


🔧 COMMON ERRORS:
═══════════════════════════════════════════════════════════════════════════

   ERROR: "npm is not recognized"
   FIX: Install Node.js from https://nodejs.org/ and restart computer

   ERROR: "Port 3000 already in use"
   FIX: Close any running Node.js processes or restart computer

   ERROR: "Cannot find module"
   FIX: Run "1_INSTALL_DEPENDENCIES.bat" again

   ERROR: Blank screen in browser
   FIX: Make sure BOTH backend and frontend are running

🛑 TO STOP THE APPLICATION:
═══════════════════════════════════════════════════════════════════════════

   1. Find the backend server window
   2. Press Ctrl+C
   
   3. Find the frontend server window  
   4. Press Ctrl+C


💡 TROUBLESHOOTING TIPS:
═══════════════════════════════════════════════════════════════════════════

   Problem: Nothing happens when clicking .bat files
   ► Right-click → "Run as administrator"
   
   Problem: Backend/Frontend won't start
   ► Make sure Node.js is installed: node --version
   ► Run "1_INSTALL_DEPENDENCIES.bat" again
   ► Restart computer
   
   Problem: Browser shows error
   ► Wait 10-15 seconds after starting servers
   ► Make sure both backend AND frontend are running
   ► Check the server windows for errors
