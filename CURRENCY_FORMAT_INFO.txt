💡 INDIAN NUMBER SYSTEM
═══════════════════════════════════════════════════════════════════════════

   The application uses the Indian numbering system:

   ₹1,000            - 1 Thousand (1K)
   ₹10,000           - 10 Thousand (10K)
   ₹1,00,000         - 1 Lakh (1L)
   ₹10,00,000        - 10 Lakh (10L)
   ₹1,00,00,000      - 1 Crore (1Cr)

═══════════════════════════════════════════════════════════════════════════

   ✓ Currency symbol changed from $ to ₹
   ✓ Prices formatted using Indian locale (en-IN)
   ✓ Proper comma separation (Indian style)
   ✓ Two decimal places for accuracy
   ✓ Green color for prices (easy to read)


🔧 TECHNICAL IMPLEMENTATION
═══════════════════════════════════════════════════════════════════════════

   Backend:
   • All prices stored in paise (smallest unit)
   • 1 Rupee = 100 Paise
   • Example: ₹899.99 is stored as 89999 paise

   Frontend:
   • Automatic conversion from paise to rupees
   • Uses Intl.NumberFormat('en-IN', { currency: 'INR' })
   • Utility function: formatINR(priceInPaise)
